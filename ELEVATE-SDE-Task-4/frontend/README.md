# CredVault Frontend (Task 4)

React + Vite frontend connected to the Task 3 backend API. The API base URL is configured with `VITE_API_BASE_URL` in `.env` (default `http://localhost:4000/api`).

Run from the repository root:

```bash
npm install
npm run dev --workspace frontend
```

See the root `README.md` for full-stack setup, backend seeding, endpoint details, and GitHub submission instructions.
